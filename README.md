
# Emotion Detection Application

## Project Description
This project implements an Emotion Detection Application using the IBM Watson NLP Emotion Prediction service.

## Features
- Detects anger, disgust, fear, joy and sadness.
- Identifies the dominant emotion.
- Provides a Flask web interface.
- Handles invalid and blank input.
- Includes unit tests.
- Uses Python requests for API communication.

## Technologies Used
- Python
- IBM Watson NLP
- Flask
- Requests
- Unittest
- Pylint

## Project Structure
- EmotionDetection/emotion_detection.py
- EmotionDetection/__init__.py
- test_emotion_detection.py
- server.py
- templates/index.html

## How to Run
1. Install dependencies.
2. Activate the virtual environment.
3. Run python server.py.
4. Open http://127.0.0.1:5000.
